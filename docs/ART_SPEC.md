# Графика: как делаются слои

Стиль — современная fashion-иллюстрация для мобильной одевалки: чистый тёмный контур,
плоская cel-заливка с мягкими тенями (референс: `art-src/ref/style-ref.png`).

## Как это устроено (v2, с 2026-11-11)

Ничего не вырезается. Модель нарисована один раз, а каждая вещь — сразу отдельный
прозрачный слой, который Codex рисует точно поверх модели. Всё лежит в `art-src/v2/`.

1. **Модель** — `art-src/v2/base.png`, 1024×1536, настоящий прозрачный фон: руки отведены
   от тела, ладони открыты, волосы убраны под гладкую «шапочку». Её не перегенерируем.
   `body.py` делает из неё гладкое тело без белья (как у манекена), а бельё становится
   двумя слоями `underwear-top` / `underwear-bottom`, которые прячутся под одеждой.
2. **Вещь** рисует Codex по образцу — картинке этой вещи в магазине
   (`art-src/raw/product/<имя>.png`), поэтому на модели и на витрине она одинаковая.
   - Причёски, верх и платья — пара слоёв (`gen_pair.sh`): `-back` (что за спиной: волосы
     за плечами, изнанка воротника и подола) рисуется под телом, `-front` — поверх.
   - Низ, украшения, сумки — один слой (`gen_layer.sh`).
   - **Правкой самой модели** — когда вещь должна точно следовать её телу: Codex «надевает»
     вещь на `base.png`, а скрипт берёт то, что изменилось. Так вещь сразу её размера и на
     её месте, подгонять нечего:
     - закрытая обувь — `gen_onbody.sh` → `onbody.py` (стопа внутри туфли — из той же
       правки, стопы тела под туфлей прячутся);
     - очки — `gen_face.sh` → `faceacc.py` (берётся только оправа, сквозь прозрачные
       линзы видны её глаза). Очки с большой цветной линзой правкой лица не делаются —
       Codex чуть перекрашивает всё лицо: их рисует `gen_layer.sh` отдельным слоем, а
       `check.fit_glasses` выравнивает их по горизонтали, ставит по её глазам и делает
       линзу полупрозрачной (оправа остаётся непрозрачной);
     - брюки и джинсы, если отдельный слой выходит не по фигуре — `gen_wear.sh` → `wear.py`;
     - макияж — `gen_makeup.sh` → `makeup.py`.
     Codex при правке может залить фон — такие правки скрипты отмечают ("backdrop").
3. **Проверка и подгонка** (`check.py`, `pairs.py`) — вердикт «годен / брак» по каждому слою:
   кожа модели внутри вещи, видно бельё, пара «сзади+спереди» не совпадает с образцом,
   из-под причёски видна шапочка, вещь выходит за холст. Брак перегенерируется.
   Подгонка автоматически:
   - низ растягивается по бёдрам и по ногам, чтобы нигде не было видно тела;
     брюки бракуются, если штанины намного шире ног или закрывают стопы;
   - сапоги ставятся по центру ноги, босоножки — по стопе (сквозь ремешки видна её стопа);
   - серьги подвешиваются петелькой на мочку, сумка — ручкой поперёк пальцев правой руки;
   - причёска закрывает шапочку модели, даже если Codex оставил щель у виска.
4. **Сборка** (`build.py`) — всё в `public/art/*.webp` и `src/art/layers.json`.
   У верха есть маска подола `<верх>-hem`: низ рисуется только ниже подола.
   Закрытая обувь делится на `<обувь>-foot` (стопа, перекрашивается под тон) и саму обувь
   (её можно красить CSS-фильтром, стопа не задевается); `cut` — с какой строки скрыть
   стопы тела. Вещи, принятые после просмотра глазами вопреки проверке (ажур не совпадает
   с образцом дырочка в дырочку), записаны в `art-src/v2/accepted.json`.
5. **Порядок в игре** (`src/art/Doll.tsx`): волосы сзади → изнанка платья/верха → тело →
   макияж → бельё (если не закрыто) → стопа и обувь → низ (под маской подола) → платье →
   верх → колье → сумка → очки → волосы спереди → серьги.

**Тон кожи** — перекраска (`art-src/skin.py`): только тела, макияжа и стоп в обуви — в
одежде и волосах кожи нет. Файлы `<имя>~<тон>.webp`, в `layers.json` — `"skin": true`.
Тоны: `TONES` в `skin.py` и `SKIN_TONES` в `Doll.tsx` (должны совпадать).

Сумки — только в руке, на коротких ручках, без кисти в слое: ручка ложится поперёк пальцев.

## Команды

Новая вещь: добавить строку в `art-src/v2/jobs-pairs.tsv` (верх, платье, причёска) или
`jobs-layers.tsv` (низ, обувь, аксессуары), сначала сделать картинку для магазина, потом:

```bash
art-src/.venv/bin/python art-src/v2/run_jobs.py 6
```

```bash
art-src/.venv/bin/python art-src/v2/build.py
```

`build.py` сам прогоняет проверки и ничего не собирает, пока есть брак; перегенерировать
конкретные вещи: `art-src/.venv/bin/python art-src/v2/run_jobs.py 4 top-hoodie dress-black`.
Посмотреть образы на всех тонах: `art-src/.venv/bin/python art-src/v2/sheet.py out.png "hair-long+top-tee+bottom-jeans"`.

Вещь по фото: картинка для магазина рисуется прямо по фото (`REF=фото art-src/gen_product.sh
<имя> "<описание>"`), дальше как обычно — она станет образцом для слоя на модели.
Пример — `art-src/ref/outfit-1.png` → кофта `top-crochet`, джинсы `bottom-baggy`, очки.

Новую вещь потом нужно добавить в `src/game/catalog.ts` (`ART_SLOT`, `ART_TAGS` и нужный
магазин). Слоты: верх, низ, платье, обувь, колье, серьги, очки, сумка.
Старый способ (вырезание сравнением, `art-src/extract.py`, `build_layers.py`) больше не используется.

## Цветовые варианты

Одна картинка даёт несколько товаров через CSS-фильтр (`TINT` в `catalog.ts`):
`hue-rotate` для цветных вещей, `sepia + hue-rotate` чтобы покрасить белое,
`grayscale + brightness` для чёрного и серебра.

## Ограничения сейчас

- Цвет волос задан самой картинкой причёски.
- Codex иногда отклоняет картинку фильтром безопасности (модель в белье) — тогда помогает
  переформулировать вещь (например, низ худи на талии вместо «укороченного»).

## Фоны ивентов

Каждому ивенту — своя сцена без людей (`art-src/backgrounds.tsv`: id ивента → описание места).
Она стоит за моделями в голосовании, за персонажем в примерочной и миниатюрой в списке ивентов.
Центр картинки оставляем спокойным, пол — на ~70% высоты, цвета приглушённые, чтобы одежда читалась.

```bash
art-src/gen_bgs.sh                         # все недостающие, по 4 параллельно (1–3 мин каждая)
art-src/gen_bg.sh gala "a palace ballroom…"  # одна
art-src/.venv/bin/python art-src/build_bg.py   # raw/bg/*.png → public/art/bg-<id>.webp
```

Пока файла нет, вместо фона показывается цвет ивента.
