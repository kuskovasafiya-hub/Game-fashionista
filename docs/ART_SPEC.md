# Графика: как делаются слои

Стиль — современная fashion-иллюстрация для мобильной одевалки: чистый тёмный контур,
плоская cel-заливка с мягкими тенями (референс: `art-src/ref/style-ref.png`).

## Как это устроено

1. **База** — `art-src/raw/base.png`, 1024×1536, белый фон: девушка в нюдовом белье,
   лицом к зрителю, руки чуть отведены от тела, гладко зачёсанные волосы.
   Её нельзя перегенерировать: все вещи нарисованы поверх именно этой картинки.
2. **Вещь** = Codex редактирует базу: «надень на неё X, всё остальное не трогай».
   Результат — `art-src/raw/<имя>.png`.
3. **Нарезка** — скрипт сравнивает картинку с базой и забирает только изменившиеся
   пиксели. Получается прозрачный слой, который точно ложится на фигуру. Правила чистоты
   краёв (`art-src/extract.py`):
   - фон — только почти идеально белые пиксели (≥ 250), поэтому белая ткань не «съедается»;
   - край вещи доходит до её чернильного контура, светлое свечение снаружи контура уходит
     в прозрачность — без белой каймы;
   - кожа, которая и на базе была кожей (тени под подолом, перерисованные руки), выкидывается;
   - старые линии базы, которые вещь стёрла (край бюстгальтера в вырезе), закрываются.
   Проверить нарезку «было/стало»: `art-src/.venv/bin/python art-src/compare.py out.png top-tee:330,260,700,660`.
4. В игре слои кладутся друг на друга: тело → стопы (если нет обуви) → обувь → низ → платье → верх → сумка → волосы → серьги.
5. **Картинка для магазина** — отдельная генерация: Codex рисует вещь целиком, без модели,
   на прозрачном фоне (`art-src/raw/product/<имя>.png`). В карточках магазина и гардероба
   показывается она, а не слой с модели.

Обувь режется иначе, чем остальное: слой забирает всю ступню ниже линии `FEET_Y`
(голень над щиколоткой), а босые стопы базы в это время скрываются.
Иначе из узкой туфли торчали бы пальцы широкой босой стопы. Если обувь выше
(сапоги), в слой добавляется и изменившаяся часть голени.

Причёска режется на два слоя: `hair-*-back` — пряди вне силуэта тела (рисуются под телом
и одеждой) и `hair-*` — пряди на плечах и лице (поверх одежды).

Вещи цвета кожи или белья (бежевое, кремовое, кэмел) режутся с пониженным порогом
(`THRESHOLDS` в `build_layers.py`), иначе сквозь них проступает тело.

## Команды

Сгенерировать вещь (1–3 минуты):

```bash
art-src/gen.sh top-hoodie "an oversized lilac hoodie with a kangaroo pocket, hem at the hips"
```

Имя файла начинается со слота: `hair-`, `top-`, `bottom-`, `dress-`, `shoes-`, `acc-`.

Картинка для магазина (после генерации самой вещи):

```bash
art-src/gen_product.sh top-hoodie "an oversized lilac hoodie with a kangaroo pocket"
```

Нарезать всё в `public/art/*.webp` и обновить `src/art/layers.json`:

```bash
art-src/.venv/bin/python art-src/build_layers.py
```

Новую вещь потом нужно добавить в `src/game/catalog.ts` (`ART_SLOT` и нужный магазин).

## Цветовые варианты

Одна картинка даёт несколько товаров через CSS-фильтр (`TINT` в `catalog.ts`):
`hue-rotate` для цветных вещей, `sepia + hue-rotate` чтобы покрасить белое,
`grayscale + brightness` для чёрного и серебра.

## Ограничения сейчас

- Один тон кожи и один макияж — варианты сделаем отдельными генерациями базы.
- Цвет волос задан самой картинкой причёски.
- Вещь, которая сливается по цвету с кожей или волосами (золото, нюд), режется хуже —
  для таких слоёв в `build_layers.py` понижен порог (`THRESHOLDS`).
